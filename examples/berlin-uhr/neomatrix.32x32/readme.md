# "Berlin-Uhr" for NeoMatrix display with 32x32 LEDs
The code for the Berlin-Uhr can be found in file berlin32.py. The details are located in the included library berlin_neomtx_32.py.

For a convenient abstraction of an X and Y addressable matrix of NeoPixels, I'm using my _neomatrix_ and _matrix32_ [modules](https://github.com/pagong/CircuitPython_NeoMatrix).
