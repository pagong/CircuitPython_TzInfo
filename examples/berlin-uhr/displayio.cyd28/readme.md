# "Berlin-Uhr" for Cheap Yellow Display with 2.8" LCD (ILI9341)
This code is for the [Cheap Yellow Display](https://circuitpython.org/board/sunton_esp32_2432S028/) with a 2.8 inch LCD display.
It is based on the _DisplayIO_ code of the "Seengreat Matrix Adapter" version.

The main code of the Berlin-Uhr can be found in file berlin_cyd28.py.
The details are located in the included library berlin_display_32.py.
