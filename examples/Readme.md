# Example usage of 'TzInfo' in various clocks

Adapt the _settings.toml_ file to your environment and put it into the root directory of your CIRCUITPY drive.

## Word Clocks
These clocks have been derived from the [article](https://adafruit-playground.com/u/VPTechOps/pages/rgb-matrix-word-clocks) "RGB Matrix Word Clocks"
which was published by Frederick M. Meyer on the _Adafruit Playground_ in 2024.
In addition to the original English version, I've created German versions for Hub75 and LCD displays.

## Berlin-Uhr
The [Berlin-Uhr](https://de.wikipedia.org/wiki/Berlin-Uhr) has been invented by Dieter Binninger in 1975. It's been publically installed in Kurfürstendamm of Berlin Charlottenburg.
The clock is showing time based on a number system with base 5. I'm providing Berlin-Uhr simulations using either _NeoMatrix_ or _DisplayIO_ graphic routines.
